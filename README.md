# TCM 网站 V2 修改说明

这份 `index.html` 是按照本次六项要求做的前端替换版，继续读取仓库中的 `cases.json` 和 `tongue/` 图片目录，不要求后端。

已实现：
1. 提交答案增加“请写出你的辨证依据”大文本框，并在提交后先给出整体评分，再允许点击“显示完整病例”。
2. 点击望诊后先展示其他望诊信息，同时弹出/打开舌象判断：舌色、舌形、舌苔；未提交舌象判断前不会公布舌象答案。提交后在线索区显示“舌色✅ / 舌形❌ / 舌苔✅”。
3. “学习记录”改为“我的错题”：记录日期、病例、主诉、我的答案、我的辨证依据；支持“重新挑战”和“查看解析”。只有重新挑战并达到正确标准后才会自动移出错题。
4. “显示完整病例”不会自动进入下一题，而是展示完整病例、标准答案、病例来源以及“可自行查找二诊/三诊”的提示。
5. 训练阶段改为：🌱 入门训练 / 🌿 综合训练 / 🌳 临床思维，并按用户指定 ID 重新分组。
6. 舌象弹窗左上角区分“原始病例照片 / 参考图”。用户指定的来源信息已写入 `CASE_META`。

注意：
- 我当前环境没有 GitHub 写权限，因此不能直接把文件 push 到你的仓库。
- 将这个 `index.html` 替换仓库原 `index.html` 后，继续使用现有 `cases.json` 即可。
- 图片路径支持从病例数据中自动查找，也会尝试 `tongue/<病例ID>.jpg/.jpeg/.png/.webp`。如果你仓库中某些图片文件名并非按病例 ID 命名，需要把对应路径补进 `guessImagePaths()` 的候选映射。
- 辨证依据评分是“关键词辅助评分”，不是权威专业评分；这是为了在纯前端、无后端的前提下实现练习功能。
