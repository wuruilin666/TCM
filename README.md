# 中医病例互动学习网站（海龟汤模式）

一个面向中医学习者的互动病例学习网站。

项目通过病例主诉（“谜面”）引导学习者自主选择「望、闻、问、切」获取线索，逐步完成辨证、病名和治法推演；提交答案后查看完整医案解析。

> 在线体验：(https://wrltcm.pages.dev/)

## 隐私与病例投稿

投稿内容会经由第三方表单服务转发给站点维护者。

投稿人必须先删除姓名、联系方式、身份证号、精确地址及其他可识别个人信息；上传的病例和舌象图片不得包含未脱敏的个人信息。

客户端仅提供基础格式和大小校验，维护者在发布前仍应进行人工审核和脱敏复核。
